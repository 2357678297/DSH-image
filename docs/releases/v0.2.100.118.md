# v0.2.100.118

- JSON 请求体改为整份表格：请求体里有几个字段就列几行，跟着实际键走，不再只挑固定的几个。
- 每行从左到右是勾选框、中文名加原始字段名、可直接编辑的值。字符串是输入框，数字是数字框，供应商/接口协议/质量/模式是下拉。
- 有中文名的字段显示中文名：提示词、用户原话、计划备注、会话、模型、供应商、尺寸、质量、张数、时长、接口协议、模式、参考图、参考图列表、内联参考图、来源、思考辅助、思考供应商、思考模型、宽高比。
- 勾选表示这一行覆盖了标准值。改哪个字段就自动勾上哪个；取消勾选立刻回到该字段的标准值。
- 会话、思考辅助、思考供应商、思考模型由工作台管理，在表里只读。数组和对象值显示摘要，需要改就切到「自定义 JSON」。
- 顶部保留「按字段编辑」/「自定义 JSON」切换，两种视图改的是同一份草稿。
- 更新后需手动重启 DSH 加载新版宿主。
