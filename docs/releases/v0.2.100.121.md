# v0.2.100.121

- 取消「按字段编辑 / 自定义 JSON」两个视图：JSON 请求体现在只有一个结构化表格编辑器，不再显示原始文本框。
- 每一行就是一个字段：勾选框、中文名、可编辑的字段名、可编辑的值、删除按钮。
- 字段名都能改（会话、思考辅助这几个由工作台管理的保持只读）。
- 数组和对象不再只显示摘要，直接在行内按 JSON 编辑，失焦即解析；写坏了会还原并提示，不会污染请求体。
- 顶部固定「加字段」栏：填字段名和值即可新增一行，值自动识别数字 / 布尔 / JSON。
- 表格放在更宽的弹窗里，一行一个字段，可视行数比之前多。
- 更新后需手动重启 DSH 加载新版宿主。
