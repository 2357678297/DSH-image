# v0.2.100.127

- 左侧导航新增「模特素材」，排在图片处理之后。
- 一位模特一张卡；卡内固定十格：全身正面 / 全身背面 / 全身侧面（比例位），加脚、手、头、耳朵、胸口、大腿、背面全头发。
- 点任意空格从图库挑图放入；格子右上角可点开重挑或清空；卡片头显示「n/10 已填」，可改名、删卡（删卡不动图库原图）。
- 生成后加入：结果卡每张图新增「加入模特」按钮，选一位模特、点一个格位即放入。
- 新接口 /muses、/muses/save、/muses/slot、/muses/delete；格子只存本站媒体地址，外链会被拒。数据落在素材目录的 models.json。
- 更新后需手动重启 DSH 加载新版宿主。
