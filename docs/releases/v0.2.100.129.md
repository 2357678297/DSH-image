# v0.2.100.129

- 图库网格与选图弹层改用缩略图（默认 256px）：实测 26MB 原图 → 75KB 小图，网格不再为 126px 的格子解码 4K 原图。
- 缩略图按「宽度 + 原文件 mtime」落盘缓存：同一张图只生成一次，之后直接读缓存（带一周 immutable 缓存头）。
- 生成顺序：先试 Electron nativeImage，拿不到就用 Windows System.Drawing 后备；两者都失败才 302 回原图，不会给空格子。
- 选图弹层改成分页（每次 40 张 + 「载入更多」），打开时不再一次性铺几百张；图片加 lazy + async 解码。
- 图库条目新增 thumbUrl 字段；模具卡格子、图库瓦片、选图缩略都走它。
- 更新后需手动重启 DSH 加载新版宿主。
