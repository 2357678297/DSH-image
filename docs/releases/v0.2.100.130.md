# v0.2.100.130

- 缩略图改用 sharp(libvips) 编码 WebP：26MB 原图 → 256px 约 6KB（上一版 JPEG 75KB），冷生成 0.64s，缓存命中 2–3ms。
- sharp 作为可选依赖：装了就走最快路；没装自动退回 Electron nativeImage，再退回 Windows System.Drawing，最后才回原图。
- 生成/上传落盘时就后台预生成缩略图（并发 2），打开图库不再等首轮生成。
- 启动时后台补齐老图库缺的缩略图（每轮最多 400 张）。
- 修正缓存键：后缀在确认 sharp 可用后再定，WebP 不会再写成 .jpg，热读真正命中。
- 修复上版遗留：缓存文件名与实际编码不一致导致每次都重编码。
- 选图弹层改用已有的懒加载缩略组件（IntersectionObserver + 内存缓存）；瓦片与弹层格子加 content-visibility，滚动跳屏外绘制。
- 更新后需手动重启 DSH；本机已装 sharp，其他机器可选 npm i sharp。
